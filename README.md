# Astrolábio - Swan Hotéis

> O diretório digital oficial e guia de hospitalidade da rede Swan Hotéis.

## 📖 Sobre o Projeto

O **Astrolábio** é uma aplicação web desenvolvida para modernizar a experiência dos hóspedes da rede **Swan Hotéis**.

Projetado para substituir os antigos diretórios de papel, ele oferece uma alternativa ecológica, higiênica e interativa. O nome é inspirado no antigo instrumento de navegação, simbolizando a precisão e a orientação que o hotel oferece aos seus visitantes. A aplicação centraliza todas as informações essenciais da estadia em uma interface acessível via QR Code diretamente no quarto.

## ✨ Destaques e Funcionalidades

A aplicação foca em **User Experience (UX)** e **Acessibilidade** para atender hóspedes do mundo todo:

* **🌍 Internacionalização Completa (i18n):** Sistema robusto de tradução com suporte instantâneo para **Português, Inglês, Espanhol e Chinês**, garantindo que nenhum hóspede se sinta perdido.
* **📱 Interface Mobile-First:** Layout totalmente responsivo, desenhado pensando primeiramente na experiência em smartphones, onde a maioria dos hóspedes acessa o serviço.
* **📂 Navegação por Acordeão:** Organização inteligente das informações para evitar "rolagem infinita", permitindo expandir apenas o que interessa:
    * Credenciais de Wi-Fi e ramais internos.
    * Horários de Café da Manhã e Restaurante.
    * Políticas do hotel e Mapa dos andares.
* **💡 Interatividade:** Modais integrados para consulta rápida de tabelas de preços (Frigobar e Lavanderia) sem sair da tela principal.
* **🔗 Conexão Direta:** Botões de ação rápida para WhatsApp da recepção, cardápios digitais externos e redes sociais.

## 🛠️ Tecnologias Empregadas

Este projeto serve como um case de implementação de tecnologias modernas do ecossistema JavaScript:

* **[React](https://reactjs.org/):** Para construção de uma interface reativa, componentizada e veloz.
* **[Vite](https://vitejs.dev/):** Utilizado para build e otimização de performance do bundle.
* **[i18next](https://www.i18next.com/):** Framework líder para gestão de internacionalização.
* **CSS Modules:** Para uma estilização segura, modular e livre de conflitos.
* **Lucide React & React Icons:** Para iconografia leve e moderna.
